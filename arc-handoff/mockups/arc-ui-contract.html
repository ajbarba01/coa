APPROVED 2026-08-07 — as guidance, not contract

Maintainer ruling: the in-arc frontend agent has maximum design freedom. Only the FUNCTIONALITY below is binding — what exists, what each affordance does. The placements and shapes drawn above are the planning session's suggested defaults; the arc's Fable agent may re-derive any of them with better design judgment (journaling the rationale when it deviates materially).

Binding functionality

  • A visible per-session mode control; four modes; risk-coded so bypass is unmistakable at a glance.
  • An always-available context-health readout reflecting the active model's real window; detail on demand.
  • Spawn / completion / A2A rendered as first-class transcript elements with jump-to-agent/thread affordances; completion delivers the child's result into the parent (inline preview + expandable, parent model receives it).
  • Subagents visible live in the right dock (children, status, jump); worktree bindings visible.
  • A skills+MCP management surface: search/discover/link-or-copy (copy carries provenance + drift + re-sync), per-agent injection config, per-server MCP health+enable, / invocation from the composer.
  • A read-only viewer holding multiple opened items (files, system prompts, tool outputs — any session), all “view” affordances route to it, opened items stay materialized.
  • Light theme = full re-tailored sand-light scale in the S7 identity direction; every primitive works in both themes.
  • All placement, layout, spacing, motion, iconography, copy: the in-arc Fable model's craft under impeccable + docs/UI.md + the kit, with the screens above as suggested defaults.
